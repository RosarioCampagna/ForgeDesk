# ForgeDesk

A Windows desktop app to create and manage Minecraft servers (vanilla, Fabric, Forge and NeoForge), with mods and modpacks from Modrinth and CurseForge, backups, and a built-in Java manager.

This repository only hosts the **releases**. The source code is not published.

## Download

Get the latest installer from the [Releases](../../releases/latest) page: `ForgeDesk_<version>_x64-setup.exe` (Windows, 64-bit).

The installer is not yet signed with a Windows code-signing certificate, so Windows SmartScreen may show "Windows protected your PC". Choose **More info** and then **Run anyway**. You can check the download against `SHA256SUMS.txt` on the release page.

ForgeDesk checks this repository for new versions and asks you before installing one. Updates are signed, and the app refuses anything that does not carry a valid signature.
